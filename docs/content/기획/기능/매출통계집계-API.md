## 개요
[[매출통계대시보드]]가 사용할 집계 데이터(일별 매출, 인기 메뉴 등)를
계산해 제공하는 API입니다.

## 예상 요구사항
- 집계 기준(일/주/월, 카테고리별 등) 범위 결정 필요
- 대량 주문 데이터 집계 시 성능 고려(사전 집계 vs 실시간 집계)
- 대시보드에서 필요한 응답 형태 정의

## 상태
아직 착수 전입니다. 실제 작업을 시작하면 `docs/AGENTS.md`의 SDD
워크플로우에 따라 LeanSpec으로 개별 스펙(`docs/specs/`)을 만들어 진행
상태를 추적합니다.
