## 개요
[[멤버십포인트조회]] 기능을 뒷받침하는 서버 측 API로, 멤버십 식별,
포인트 적립/차감 로직을 처리합니다.

## 예상 요구사항
- 멤버십/포인트 데이터 모델 설계 필요
- 포인트 적립/사용 정책 확정 필요(도메인 정책 판단 필요)
- 동시 주문 시 포인트 차감 정합성 처리 방식 결정

## 상태
아직 착수 전입니다. 실제 작업을 시작하면 `docs/AGENTS.md`의 SDD
워크플로우에 따라 LeanSpec으로 개별 스펙(`docs/specs/`)을 만들어 진행
상태를 추적합니다.
