## 개요
고객이 "주문하기"를 누르면 장바구니 내용이 주문으로 서버에 제출됩니다.
성공 시 장바구니가 비워지고, 실패 시 안내 메시지만 뜨고 장바구니 내용은
유지됩니다. 제출 중에는 로딩 상태가 표시됩니다.

## 동작 방식
`features/cart`의 주문 제출 액션이 백엔드의 `POST /api/orders`를
호출합니다. 요청 바디는 `packages/types`의 `CreateOrderInput` 타입을
따르며, 요청 진행 중에는 로딩 상태 플래그를 켜서 UI에 반영합니다. 성공
응답을 받으면 장바구니를 초기화하고, 실패하면 에러 메시지만 노출한 채
장바구니는 그대로 둡니다.

## 관련 코드
- `apps/frontend/src/features/cart`
- `apps/backend` (`POST /api/orders`)
- `packages/types` (`CreateOrderInput`)
