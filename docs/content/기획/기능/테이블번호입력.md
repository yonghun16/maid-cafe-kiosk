## 개요
매장 내 취식([[매장내포장선택]] 참고) 시 주문한 메뉴를 어느 테이블로
서빙할지 알아야 하는 매장이라면, 주문 단계에서 테이블 번호를 입력받아야
합니다.

## 예상 요구사항
- 테이블 번호 입력 UI(숫자패드 등)
- 입력값을 주문 데이터에 포함해 [[실시간주방디스플레이KDS]] 등에서 참조
- 테이블 번호 유효성 검증 방식 결정

## 상태
아직 착수 전입니다. 실제 작업을 시작하면 `docs/AGENTS.md`의 SDD
워크플로우에 따라 LeanSpec으로 개별 스펙(`docs/specs/`)을 만들어 진행
상태를 추적합니다.
