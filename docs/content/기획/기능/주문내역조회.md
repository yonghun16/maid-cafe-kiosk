## 개요
관리자 화면(`/admin`)의 "주문 내역" 탭에서 들어온 주문을 최신순으로
확인할 수 있습니다. 검색/필터, 주문 상태 변경(접수/준비중/완료 등)은
아직 없어 전체 상태는 작업중입니다.

## 완료: 주문 목록 조회
`/admin`에서 "주문 내역" 탭을 누르면 전체 주문을 최신순으로 보여줍니다.
10초마다 자동으로 갱신되고, "새로고침" 버튼으로 즉시 갱신할 수도
있습니다. 각 주문 카드에는 매장/포장 구분, 담긴 메뉴와 수량, 합계
금액, 주문 시각이 표시됩니다. 실시간 푸시(WebSocket) 없이 폴링
방식으로만 구현했습니다 — 더 즉각적인 갱신이 필요해지면
[[실시간주방디스플레이KDS]]로 업그레이드를 검토합니다.

### 관련 코드
- `apps/backend/src/index.ts` — `GET /api/orders`(`requireAdmin`으로
  보호, 최신순 정렬)
- `apps/frontend/src/entities/order` (`getOrders`, `OrderCard`)
- `apps/frontend/src/widgets/order-list/ui/OrderList.tsx` (10초 폴링 +
  수동 새로고침)
- `apps/frontend/src/views/admin/ui/AdminPage.tsx` ("메뉴 관리"/"주문
  내역" 탭 전환)
- `packages/types`의 `Order`, `OrderItem`

## 작업전: 검색/필터, 상태 변경
- 검색/필터 기능(날짜, 상태 등)
- [[주문상태전이-API]]와 연계한 상태 변경 UI

아직 착수 전입니다. 실제 작업을 시작하면 `docs/AGENTS.md`의 SDD
워크플로우에 따라 LeanSpec으로 개별 스펙(`docs/specs/`)을 만들어 진행
상태를 추적합니다.
