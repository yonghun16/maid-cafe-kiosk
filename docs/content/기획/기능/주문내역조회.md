## 개요
**주방 화면(`/kitchen`)**에 "진행중 주문"/"지난 주문" 두 탭이 있어
들어온 주문을 최신순으로 확인하고, 완료 처리할 수 있습니다. 검색/필터,
더 세분화된 상태 전이(접수→준비중→완료→픽업)는 아직 없어 전체 상태는
작업중입니다.

처음엔 `/admin`(관리자 화면) 안의 탭이었는데, 메뉴/광고/통계 관리와
섞여 있으면 주문만 계속 지켜봐야 하는 주방/카운터 직원 입장에서
불필요하게 산만하다고 판단해 **`/kitchen`이라는 별도 화면으로
분리**했습니다. 로그인 세션은 `/admin`과 동일한 공유 비밀번호 기반
세션을 그대로 쓰므로(같은 쿠키를 공유해 한쪽에 로그인하면 다른 쪽도
바로 접근 가능), 이번 분리는 **화면 구성만** 나눈 것이고 권한 분리는
포함하지 않습니다(권한 구분이 필요해지면 [[관리자인증인가]]에서 별도
검토). 두 화면은 헤더의 "주방 화면"/"관리자 화면" 링크로 서로 오갈 수
있습니다.

## 완료: 주문 목록 조회 + 완료 처리
`/kitchen`의 "진행중 주문" 탭은 아직 완료되지 않은 주문을, "지난 주문"
탭은 완료 처리된 주문을 최신순으로 보여줍니다. 둘 다 10초마다 자동
갱신되고, "새로고침" 버튼으로 즉시 갱신할 수도 있습니다. 각 주문
카드에는 매장/포장 구분, **주문번호**, 메뉴 이미지·이름·수량, 합계
금액, **날짜+주문 시각**이 표시됩니다. "진행중 주문" 카드에만 "완료"
버튼이 있어 누르면 그 주문이 "지난 주문" 탭으로 넘어갑니다(상태는
`isCompleted` 단일 boolean — 접수/준비중 같은 중간 단계는 없음). 실시간
푸시(WebSocket) 없이 폴링 방식으로만 구현했습니다. 포트폴리오 프로젝트
규모라 이 이상의 전용 KDS 하드웨어/실시간 인프라 연동은 범위에 넣지
않았습니다.

주문번호는 MongoDB의 긴 `_id` 대신, **한국 시간(KST) 기준 당일
자정부터 1번씩 다시 매기는 짧은 번호**입니다(스타벅스 매장 주문번호
방식 — "23번 손님" 처럼 호출하기 좋게). 별도 카운터 컬렉션 없이, 주문
생성 시점에 오늘 자정(KST) 이후 생성된 주문 수를 세어 `+1`한 값을
그대로 저장합니다. 동시에 여러 주문이 들어오면 이론상 번호가 겹칠 수
있지만, 매장 1곳·순차적인 방문 트래픽이라는 현재 규모에서는 감수할
만한 트레이드오프로 판단했습니다.

이 화면은 주로 PC에서 쓴다는 점을 고려해 데스크탑 위주로 만들었습니다
— 목록은 화면 폭에 따라 1~3열 그리드로 배치되고, 글자·이미지 크기를
크게 잡아 멀리서도 알아보기 쉽게 했습니다. 메뉴 관리 탭의 목록도 같은
이유로 이미지/글자 크기를 키웠습니다. 주문 항목에는 상품 자체가 아니라
**주문 시점의 이름/가격/이미지 스냅샷**(`OrderItem`)이 저장되므로,
나중에 상품 이미지가 바뀌거나 상품이 삭제돼도 과거 주문에 찍힌 이미지는
그대로 남습니다.

### 관련 코드
- `apps/backend/src/index.ts` — `GET /api/orders`(`requireAdmin`으로
  보호, `status=pending|completed` 쿼리로 필터링, 최신순 정렬),
  `PATCH /api/orders/:id/complete`(완료 처리), `POST /api/orders`의
  `getKstStartOfToday`/`orderNumber` 계산 로직
- `apps/backend/src/models/Order.ts` (`isCompleted` 필드)
- `apps/frontend/src/entities/order` (`getOrders`, `completeOrder`,
  `OrderCard`)
- `apps/frontend/src/widgets/order-list/ui/OrderList.tsx` (`status` prop
  으로 진행중/지난 주문 전환, 10초 폴링, 수동 새로고침, 반응형 그리드)
- `apps/frontend/src/views/kitchen/ui/KitchenPage.tsx` (`/kitchen` —
  "진행중 주문"/"지난 주문" 2개 탭, `/admin`으로 가는 링크)
- `apps/frontend/src/app/kitchen/page.tsx` (라우트 진입점)
- `apps/frontend/src/views/admin/ui/AdminPage.tsx` (`/admin` — "메뉴
  관리"/"광고 관리"/"판매 통계" 3개 탭 + `/kitchen`으로 가는 링크)
- `packages/types`의 `Order`(`orderNumber`, `isCompleted` 필드),
  `OrderItem`, `OrderStatusFilter`
