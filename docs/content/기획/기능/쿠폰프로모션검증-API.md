## 개요
[[쿠폰코드적용]]에서 입력된 쿠폰 코드가 실제로 유효한지(존재 여부, 유효
기간, 사용 가능 여부 등) 서버에서 검증하는 API입니다.

## 예상 요구사항
- 쿠폰 데이터 모델 및 저장소 필요(→ [[프로모션쿠폰관리]])
- 검증 실패 사유(만료, 이미 사용됨 등)를 구체적으로 반환
- 주문 생성 시점에 쿠폰 적용 이력을 기록할지 결정

## 상태
아직 착수 전입니다. 실제 작업을 시작하면 `docs/AGENTS.md`의 SDD
워크플로우에 따라 LeanSpec으로 개별 스펙(`docs/specs/`)을 만들어 진행
상태를 추적합니다.
