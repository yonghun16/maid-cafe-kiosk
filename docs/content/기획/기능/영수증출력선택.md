## 개요
종이 영수증 발급 여부를 고객이 선택할 수 있게 해 불필요한 종이 낭비를
줄이고, 모바일 발송 등 대안을 제공하는 기능입니다.

## 예상 요구사항
- 출력/미출력/모바일 발송 선택 UI
- 모바일 발송 시 연락처 입력 방식 결정 필요
- [[영수증주방프린터연동]]과 연계해 실제 프린터 하드웨어 제어 필요

## 상태
아직 착수 전입니다. 실제 작업을 시작하면 `docs/AGENTS.md`의 SDD
워크플로우에 따라 LeanSpec으로 개별 스펙(`docs/specs/`)을 만들어 진행
상태를 추적합니다.
