## 개요
카테고리(`coffee`|`ade`|`dessert`)가 코드에 고정된 enum이던 것을 관리자
화면에서 직접 추가·수정·삭제할 수 있는 동적 데이터로 전환했습니다.
`/admin`의 "카테고리 관리" 탭에서 다룹니다.

## 동작 방식
`Category` 컬렉션(`{ name }`)이 카테고리 목록의 원본입니다. `Product.category`는
Category의 id가 아니라 **이름 문자열을 그대로 참조**합니다 — 그래서:
- **카테고리 이름을 수정**하면(`PUT /api/categories/:id`) 그 이름을 쓰던
  모든 상품의 `category` 필드도 새 이름으로 함께 갱신됩니다
  (`Product.updateMany`).
- **카테고리를 삭제**하면(`DELETE /api/categories/:id`) 그 카테고리에
  속한 상품이 전부 함께 삭제됩니다(`Product.deleteMany`). 관리자 화면에서
  삭제 전 "소속 메뉴도 함께 삭제됩니다" 확인창을 거칩니다.

기존에 고정 enum으로 저장돼 있던 상품 데이터(`coffee`/`ade`/`dessert`)를
별도로 마이그레이션하지 않기 위해, 백엔드가 시작할 때 `Category` 컬렉션이
비어 있으면 `Product.distinct('category')`로 이미 쓰이고 있는 카테고리
값들을 자동으로 채워 넣습니다(`ensureDefaultCategories`, 1회성·멱등).
그래서 기존 상품이 가리키던 카테고리 이름이 그대로 카테고리 목록에
나타나며, 관리자가 이후 원하는 이름으로 수정하면 됩니다.

카테고리가 완전히 자유 입력이 되면서, 상품 카드의 카테고리별 고정
색상(커피=주황, 에이드=초록 등)은 의미가 없어져 하나의 통일된 스타일로
단순화했습니다.

**순서 변경**: 각 카테고리는 `order`(숫자) 필드를 가지며, 값이 작을수록
앞에 표시됩니다. 관리자 화면에서 항목의 ▲/▼ 버튼을 누르면 바로 위/아래
항목과 순서가 바뀝니다. `PATCH /api/categories/reorder`가 원하는 순서로
나열한 카테고리 id 배열을 통째로 받아 배열 인덱스를 그대로 `order` 값으로
저장합니다. 새 카테고리는 항상 맨 뒤 순서로 추가됩니다. 이 순서는 고객
화면의 카테고리 필터, 관리자 화면의 메뉴 등록/수정 폼의 카테고리 목록에도
그대로 반영됩니다(전부 서버가 내려주는 순서를 그대로 씀). `order` 필드가
생기기 전에 이미 있던 카테고리는 서버 시작 시 이름순으로 순서를 자동
부여합니다(`ensureCategoryOrder`, 1회성·멱등).

### 관련 코드
- `apps/backend/src/models/Category.ts` (`name`, `order` 필드, `name`
  unique 인덱스)
- `apps/backend/src/models/Product.ts` (`category`에서 고정 `enum` 제거)
- `apps/backend/src/index.ts` — `GET/POST /api/categories`,
  `PUT/DELETE /api/categories/:id`, `PATCH /api/categories/reorder`
  (`requireAdmin`으로 보호, `GET`만 공개), `ensureDefaultCategories`/
  `ensureCategoryOrder`(자동 시딩)
- `apps/frontend/src/entities/category` (`getCategories`, `createCategory`,
  `updateCategory`, `deleteCategoryById`, `reorderCategories`)
- `apps/frontend/src/features/category-management/model/store.ts`
  (`useCategoryStore`, `moveCategory`가 낙관적 업데이트로 즉시 반응)
- `apps/frontend/src/widgets/manage-category-list/ui/ManageCategoryList.tsx`
  (추가/인라인 수정/삭제/▲▼ 순서 변경 UI)
- `apps/frontend/src/views/admin/ui/AdminPage.tsx` ("카테고리 관리" 탭)
- `apps/frontend/src/widgets/add-product-form`,
  `manage-product-list/ui/EditProductForm.tsx` (카테고리 select를 하드코딩
  대신 동적 목록으로 교체)
- `apps/frontend/src/widgets/product-list/ui/ProductList.tsx` (고객 화면
  카테고리 필터도 동적 목록으로 교체)
- `apps/frontend/src/entities/product/ui/ProductCard.tsx` (카테고리별
  고정 색상 제거, 통일된 스타일로 단순화)
- `packages/types`의 `Category`(`order` 필드), `CategoryInput`,
  `ReorderCategoriesInput`, `Product.category`(고정 union → `string`)
