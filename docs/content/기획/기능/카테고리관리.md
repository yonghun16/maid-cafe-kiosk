## 개요
현재 카테고리(`coffee`|`ade`|`dessert`)는 코드에 고정된 enum으로
관리되고 있어, 새 카테고리를 추가하려면 코드 수정이 필요합니다. 카테고리
관리 기능은 이를 관리자 화면에서 직접 다룰 수 있게 합니다.

## 예상 요구사항
- 카테고리 CRUD 화면
- 기존 고정 enum에서 동적 카테고리 데이터로 전환하는 마이그레이션 필요
- 카테고리 삭제 시 소속 메뉴 처리 정책 결정 필요

## 상태
아직 착수 전입니다. 실제 작업을 시작하면 `docs/AGENTS.md`의 SDD
워크플로우에 따라 LeanSpec으로 개별 스펙(`docs/specs/`)을 만들어 진행
상태를 추적합니다.
