## 개요
현재는 단일 매장을 전제로 데이터가 설계되어 있습니다(상품, 주문 모두
매장 구분 없음). 프랜차이즈 등으로 확장하려면 매장 단위로 데이터를
분리해야 합니다.

## 예상 요구사항
- 상품/주문 등 기존 데이터 모델에 매장(store) 식별자 추가 필요
- 기존 데이터 마이그레이션 방식 결정
- [[다중키오스크모니터링]]과 연계한 매장별 관리 화면 필요

## 상태
아직 착수 전입니다. 실제 작업을 시작하면 `docs/AGENTS.md`의 SDD
워크플로우에 따라 LeanSpec으로 개별 스펙(`docs/specs/`)을 만들어 진행
상태를 추적합니다.
