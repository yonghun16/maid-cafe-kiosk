## 개요
처음엔 "옵션 그룹/옵션 항목을 별도 화면에서 등록하고, 상품마다 어떤
그룹을 연결할지 매핑하는" 형태를 예상했지만, 실제 요청은 "메뉴를 추가할
때 그 메뉴만의 옵션을 바로 추가할 수 있게 해달라"는 더 단순한 것이었고,
그렇게 범위를 좁혀 구현했습니다.

**메뉴별 자유 옵션**은 이름과 추가금(원, 0원도 가능)으로만 이뤄진
가장 단순한 형태입니다. 관리자가 메뉴 추가/수정 폼에서 옵션을 원하는
만큼 추가·삭제할 수 있고, 여러 메뉴가 옵션 세트를 재사용해야 하는
요구가 생기면 그때 별도 옵션 그룹 관리 화면을 다시 검토합니다. 온도
(HOT/ICE)·샷 추가·마법의 주문처럼 매장 전체에 고정으로 적용되는 옵션
([[상품옵션선택]] 참고)과는 구분되는, 메뉴마다 다르게 설정하는
추가 옵션 레이어입니다.

## 동작 방식
- 관리자가 메뉴 추가/수정 폼에서 "메뉴 옵션" 영역의 "+ 옵션 추가"를
  누르면 이름/추가금 입력 줄이 하나 생기고, 여러 개를 자유롭게
  추가·삭제할 수 있습니다. 이름을 비워둔 줄은 저장 시 자동으로
  제외됩니다.
- 저장하면 `Product.options`에 `{ name, price }` 배열로 저장됩니다.
  수정 폼은 옵션 목록을 항상 전체 다시 보내므로, 옵션을 전부 지우고
  저장하면 실제로 전부 삭제됩니다(재고 수량처럼 "생략하면 기존 값
  유지"가 아님).
- 고객 화면에서 메뉴를 클릭하면 이 메뉴에 등록된 옵션이 있을 때만
  옵션 선택 모달에 체크박스 목록으로 나타납니다(없으면 이 영역 자체가
  보이지 않음). 여러 개를 동시에 선택할 수 있고, 선택한 옵션의 추가금이
  모두 합산돼 최종 가격에 반영됩니다.
- 장바구니에 담을 때 선택한 옵션들을 `selectedOptions`로 이름+가격
  스냅샷을 남깁니다. 이후 관리자가 메뉴 옵션을 수정/삭제해도 이미
  담긴 장바구니나 지난 주문 내역은 영향받지 않습니다. 같은 메뉴라도
  선택한 옵션 조합이 다르면 장바구니에서 다른 줄로 취급합니다
  (`cartItemId`에 선택한 옵션 이름들을 포함).
- 주문 내역/주방 화면([[주문내역조회]])에도 선택된 옵션이 이름 그대로
  배지로 표시돼, 주방에서 어떤 옵션이 추가됐는지 바로 확인할 수
  있습니다.

## 관련 코드
- `packages/types`의 `ProductOption`(`{ name, price }`),
  `Product.options`, `ProductInput.options`, `CartItem.selectedOptions`,
  `OrderItem.selectedOptions`
- `apps/backend/src/models/Product.ts` (`options` 배열 필드),
  `apps/backend/src/models/Order.ts` (`items.selectedOptions` 배열 필드)
- `apps/backend/src/index.ts` (`POST/PUT /api/products`가 `options`를
  저장. 수정 시엔 항상 `options ?? []`로 덮어써서 폼에서 지운 옵션이
  실제로 삭제되게 함)
- `apps/frontend/src/entities/product/ui/ProductOptionsEditor.tsx`
  (이름+추가금 입력 줄을 추가/삭제하는 재사용 UI, 메뉴 추가/수정 폼
  양쪽에서 사용)
- `apps/frontend/src/widgets/add-product-form/ui/AddProductForm.tsx`,
  `apps/frontend/src/widgets/manage-product-list/ui/EditProductForm.tsx`
  (`ProductOptionsEditor` 사용, 이름 없는 옵션 줄은 저장 전 필터링)
- `apps/frontend/src/entities/product/ui/ProductCard.tsx` (옵션 선택
  모달에 `product.options`를 체크박스로 렌더링, 선택된 옵션 가격
  합산)
- `apps/frontend/src/features/cart/model/store.ts` (`addToCart`가
  `selectedOptions`를 받아 가격에 합산하고 `cartItemId`에 반영)
- `apps/frontend/src/widgets/order-summary/ui/OrderSummary.tsx`,
  `apps/frontend/src/entities/order/ui/OrderCard.tsx` (선택된 옵션을
  이름 배지로 표시)

## 범위 밖
- 옵션을 별도 화면에서 등록하고 여러 메뉴에 재사용하는 "옵션 그룹"
  모델 — 지금은 메뉴마다 완전히 독립적으로 옵션을 등록합니다.
- 옵션별 재고 추적, 옵션 조합에 따른 품절 처리.
