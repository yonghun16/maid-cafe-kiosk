## 개요
고객이 조작하지 않는 동안 키오스크 화면이 비어 있으면 매장 브랜딩이나
홍보 효과를 놓치게 됩니다. 대기 화면은 일정 시간 미조작 시 프로모션
이미지나 인기 메뉴를 슬라이드 형태로 보여줘 매장 앞을 지나는 고객의
시선을 끄는 용도로 쓰입니다.

## 예상 요구사항
- 일정 시간(예: 30초~1분) 미조작 시 대기 화면으로 전환
- 화면 터치/클릭 시 즉시 메뉴 화면으로 복귀
- 노출할 프로모션/메뉴 이미지를 관리자가 교체할 수 있어야 함 (→
  [[대기화면배너관리]])

## 상태
아직 착수 전입니다. 실제 작업을 시작하면 `docs/AGENTS.md`의 SDD
워크플로우에 따라 LeanSpec으로 개별 스펙(`docs/specs/`)을 만들어 진행
상태를 추적합니다.
