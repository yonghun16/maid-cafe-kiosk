## 개요
현재 주문은 생성만 되고 이후 상태를 추적하는 개념이 없습니다. 주문 상태
전이 API는 매장 운영 흐름(접수/준비중/완료/픽업)에 맞춰 주문 상태를
변경할 수 있게 합니다.

## 예상 요구사항
- 주문 데이터 모델에 상태 필드 추가 필요
- 상태 전이 규칙(어떤 상태에서 어떤 상태로만 이동 가능한지) 정의
  필요(도메인 정책 판단 필요)
- [[주문내역조회]], [[실시간주방디스플레이KDS]]에서 이 API를 사용

## 상태
아직 착수 전입니다. 실제 작업을 시작하면 `docs/AGENTS.md`의 SDD
워크플로우에 따라 LeanSpec으로 개별 스펙(`docs/specs/`)을 만들어 진행
상태를 추적합니다.
