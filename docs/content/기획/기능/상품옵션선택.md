## 개요
"메뉴를 선택하면 옵션을 선택할 수 있게 해달라"는 요청으로 시작했고,
**옵션은 "샷 추가"와 "마법의 주문" 두 가지만** 넣기로 범위를 좁혔습니다
(사이즈, HOT/ICE, 시럽 등 다른 옵션 그룹은 이번 범위에 넣지 않음). 그래서
[[옵션조합관리]]가 예상했던 "옵션 그룹을 관리자가 등록/관리하는 화면"도
만들지 않고, 옵션 값(샷 추가 가격 700원, 마법의 주문 항목 4개)은 코드에
상수로 고정했습니다 — 여러 옵션을 관리자가 직접 추가/수정해야 하는
요구가 생기면 그때 옵션 그룹 데이터 모델과 관리 화면을 새로 설계합니다.

**마법의 주문**은 메이드 카페에서 서빙할 때 직원이 함께 외쳐주는 주문
(呪文)을 고객이 미리 고르는, 메이드 카페 컨셉의 재미 옵션입니다. 실제
음료/음식 구성이나 가격에는 영향이 없고, "모에모에뀽", "오이시쿠나레",
"냥냥쿵", "하피네스차지!" 네 항목 중 하나를 드롭다운으로 고릅니다
(선택 안 함도 가능).

## 동작 방식
- 고객 화면에서 메뉴 카드를 클릭하면 예전처럼 바로 장바구니에 담기는
  대신, **옵션 선택 모달**(`shared/ui/Modal` 재사용)이 뜹니다. 모달에는
  왼쪽에 메뉴 사진, 오른쪽에 "샷 추가" 체크박스(+700원)와 "마법의 주문"
  드롭다운이 있고, 아래에 옵션 반영된 최종 가격과 "담기" 버튼이
  있습니다. 처음엔 사진을 위, 옵션을 아래에 뒀는데 사진이 가로로 넓은
  틀(`h-40 w-full`)에 눌려 잘려 보였습니다 — 사진을 **왼쪽에, 상품
  카드와 같은 3:4 비율 그대로** 두고 옵션을 오른쪽에 배치해 해결했습니다.
- **장바구니 줄 구분**: 같은 메뉴라도 옵션 조합(샷 추가 여부 + 마법의
  주문 선택값)이 다르면 다른 줄로 취급해야 해서, 상품 `_id`와 별개로
  장바구니 전용 `cartItemId`를 새로 도입했습니다(`makeCartItemId`가
  `"<productId>"`, `"<productId>:extra-shot"`,
  `"<productId>:spell:모에모에뀽"`, `"<productId>:extra-shot:spell:..."`
  처럼 조합해 만듦). 수량 증감/삭제 버튼도 전부 `cartItemId` 기준으로
  바뀌었습니다(기존엔 상품 `_id`를 그대로 키로 썼는데, 옵션이 생기면서
  같은 상품이 여러 줄로 존재할 수 있게 돼 더 이상 유일하지 않아
  이렇게 바꿨습니다).
- **가격 처리**: 샷 추가 추가금만 장바구니에 담는 시점에 이미 상품
  가격에 더해서 저장합니다(`CartItem.price` = 기본가 + 샷 추가 시
  700원). 마법의 주문은 가격에 영향이 없습니다. 주문 생성 시 가격이
  그대로 `OrderItem.price`로 전달되므로, 총액 계산이나
  [[매출통계대시보드]]의 매출 집계(`item.price * item.quantity` 합산)도
  별도 처리 없이 옵션 추가금까지 자동으로 포함됩니다.
- **주문 내역/주방 화면 표시**: `OrderItem.hasExtraShot`/`magicSpell`이
  저장되고, 주문 내역 카드([[주문내역조회]])와 장바구니 목록 양쪽에
  "샷 추가" 배지, "🪄 (고른 주문)" 표시가 붙어서 주방에서 놓치지
  않게 했습니다.
- **`OrderItem._id` 노출**: MongoDB가 주문의 하위 문서(각 아이템)마다
  자동으로 `_id`를 부여하는데, 원래 타입에는 선언돼 있지 않았습니다.
  같은 상품이 옵션만 다르게 여러 줄로 들어간 주문에서 `productId`만으로는
  React 리스트 key가 겹칠 수 있어서, 이번에 `OrderItem._id`(선택
  필드 — 주문 생성 요청 바디에는 없고 저장된 주문 응답에만 있음)를
  타입에 추가하고 주문 내역 카드의 key로 씁니다.

## 관련 코드
- `packages/types`의 `CartItem.cartItemId`/`hasExtraShot`/`magicSpell`,
  `OrderItem.hasExtraShot`/`magicSpell`/`_id`(선택)
- `apps/backend/src/models/Order.ts` (`items.hasExtraShot`/`magicSpell`
  필드 추가)
- `apps/frontend/src/entities/product/model/optionConstants.ts`
  (`EXTRA_SHOT_PRICE = 700`, `MAGIC_SPELL_OPTIONS` 4항목)
- `apps/frontend/src/entities/product/ui/ProductCard.tsx` (클릭 시
  옵션 모달 — 왼쪽 사진(3:4)/오른쪽 옵션 레이아웃, "담기" 버튼)
- `apps/frontend/src/features/cart/model/store.ts` (`makeCartItemId`,
  `addToCart`가 옵션을 받아 가격/줄 구분에 반영, 수량 증감/삭제가
  `cartItemId` 기준으로 동작)
- `apps/frontend/src/widgets/order-summary/ui/OrderSummary.tsx`
  (장바구니 목록에 "(샷 추가)"/"🪄 (마법의 주문)" 표시, `cartItemId`
  기준 조작)
- `apps/frontend/src/entities/order/ui/OrderCard.tsx` (주문 내역/주방
  화면에 "샷 추가"/"🪄 (마법의 주문)" 배지 표시)
