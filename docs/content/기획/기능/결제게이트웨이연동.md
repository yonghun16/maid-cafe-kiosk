## 개요
[[결제수단선택]] 화면이 실제로 동작하려면 서버 측에서 PG사 API 연동,
카드 리더 하드웨어 연동, 결제 완료/실패 웹훅 처리가 필요합니다. 결제
수단 정보(카드번호 등) 자체는 서버에 저장하지 않는 것이 원칙입니다.

## 예상 요구사항
- 실제 결제 연동 여부 자체가 먼저 결정 필요([[개발계획서]] 로드맵 참고)
- PG사 선정 및 API 연동 방식 결정
- 결제 실패/취소/환불 처리 흐름 설계

## 상태
아직 착수 전입니다. 실제 작업을 시작하면 `docs/AGENTS.md`의 SDD
워크플로우에 따라 LeanSpec으로 개별 스펙(`docs/specs/`)을 만들어 진행
상태를 추적합니다.
