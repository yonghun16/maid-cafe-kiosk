## 개요
고객이 키오스크 첫 화면(`/`)에서 카테고리 탭을 선택해 해당 카테고리의 메뉴만
걸러볼 수 있는 기능입니다.

## 동작 방식
상품 목록을 카테고리(`coffee`|`ade`|`dessert`) 기준으로 필터링해 보여주며,
"전체" 선택 시 모든 상품을 보여줍니다. 위젯이 현재 선택된 카테고리 상태를
관리하고, 실제 상품 데이터와 카드 UI는 `entities/product`를 통해 가져옵니다.

## 관련 코드
- `apps/frontend/src/widgets/product-list`
- `apps/frontend/src/entities/product`
