## 개요
매장 운영 의사결정을 돕기 위해 매출 추이와 인기 메뉴 등을 시각화해
보여주는 대시보드입니다.

## 예상 요구사항
- 조회할 지표(일별/월별 매출, 인기 메뉴 TOP N 등) 범위 결정 필요
- [[매출통계집계-API]]와 연계한 집계 데이터 조회
- 차트/그래프 UI 구성

## 상태
아직 착수 전입니다. 실제 작업을 시작하면 `docs/AGENTS.md`의 SDD
워크플로우에 따라 LeanSpec으로 개별 스펙(`docs/specs/`)을 만들어 진행
상태를 추적합니다.
